# Инструкция к проекту и защита (Abai — Personal Page)

## 1. Как открыть проект
1. Распакуйте архив (или откройте папку проекта `html hw`).
2. Дважды кликните по файлу `Abai.html` — сайт откроется в любом браузере (Chrome, Edge, Firefox, Safari).
3. Дополнительные страницы хобби: `Aviation.html`, `Motorsport.html`, `Technique.html`.

---

## 2. Реализованные JavaScript-функции (`abai.js`)

1. **Переключение темы (Светлая / Тёмная)**:
   - Кнопка `🌙 Dark / ☀️ Light` в меню навигации.
   - Реализована через CSS-переменные (`:root` и `body.dark-theme`).
   - При переключении меняется не только фон сайта, но и:
     - Фон страницы (`--bg-body`): со светло-серого на глубокий тёмный `#121212`.
     - Фон плашек с текстом (`--bg-card`): с белого на тёмно-серый `#262626`.
     - Цвет текста (`--text-main`): с чёрного `#1e1e1e` на светлый `#f5f5f5`.
     - Фон панели (`--bg-panel`): с яркого неоново-зелёного на благородный тёмно-зелёный `#1b2e16`.
     - Поля ввода формы: со светлых на тёмные с белым шрифтом.
   - Запоминает выбор пользователя в `localStorage` (ключ `abai-theme`), поэтому тема сохраняется при перезагрузке и переходе между страницами.

2. **Кнопка «Наверх» (Back to Top)**:
   - Кнопка `↑ Top` появляется в нижнем правом углу экрана, когда страница прокручена вниз более чем на 250px (слушатель события `window.scroll`).
   - При клике плавно возвращает пользователя в начало страницы с помощью `window.scrollTo({ top: 0, behavior: 'smooth' })`.

3. **Валидация формы контактов (Contacts Form)**:
   - Форма содержит поля с явными `<label for="...">`: Имя (`name`), Email (`email`), Сообщение (`message`).
   - При отправке (`submit`) отменяется стандартная перезагрузка (`e.preventDefault()`).
   - Проверяется:
     - Имя: не пустое и минимум 2 символа.
     - Email: проверяется регулярным выражением на наличие `@` и домена.
     - Сообщение: не менее 5 символов.
   - При ошибках под полями выводятся понятные красные сообщения.
   - При успешном заполнении выводится зелёное уведомление об успешной отправке, а форма очищается (`form.reset()`).

4. **Плавная якорная навигация и мобильная адаптивность**:
   - Клик по ссылкам меню (`#about`, `#contacts`) плавно скроллит страницу к нужному блоку (`scrollIntoView({ behavior: 'smooth' })`).
   - Мобильная версия перестраивает сетку в одну колонку без горизонтальной полосы прокрутки.

## 3. Шпаргалка для защиты (Project Defense)

### Структура HTML:
- `<header>` — шапка с названием («Personal page») и навигацией `<nav>`.
- `<main>` — основное содержимое (Hero с именем и цитатой, секции «About me», «And to get down to business», «Outside of work», «Now», «Contacts»).
- `<section>` и `<article>` — логические блоки текста и карточки увлечений.
- `<aside>` — боковая колонка с блоком хобби (`#hobbies`) и изображениями.
- `<footer>` — подвал страницы с копирайтом.

### Стили CSS:
- `box-sizing: border-box` — отступы и границы включаются в общую ширину блоков, предотвращая поломку верстки.
- `.page` — CSS Grid (`grid-template-columns: 660px 400px` на ПК, `1fr` на экранах меньше 860px).
- Цветовая палитра: `#1e1e1e` (тёмный фон), `#4cf20f` (неоновый зелёный акцент), `#2b10ff` (синий акцент разделителя), `#ffffff` (контентные плашки).
- Шрифты: `"Hammersmith One"`, подключён через Google Fonts.
